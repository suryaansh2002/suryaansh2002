### Featured projects

- **[regex-llama-1b](https://github.com/suryaansh2002/regex-llama-1b)** —
  LoRA fine-tuned Llama-3.2-1B for natural-language → regex generation;
  outperformed gpt-oss-120b and Llama-3-70B on the in-distribution eval set,
  trained in ~13 minutes on a single MacBook (MLX)
- **[Gmail RAG](https://github.com/suryaansh2002/gmail-rag)** — full-stack RAG
  app for querying your own Gmail in natural language (OAuth-secured
  ingestion, Pinecone, local Ollama LLM, FastAPI + Next.js)
- **[Real-Time Meeting Summarizer](https://github.com/suryaansh2002/real_time_meeting_sumarizer)** —
  Chrome extension + FastAPI backend that transcribes live meeting audio
  (Whisper), summarizes with Mistral-7B, and extracts speakers + action items
- **[Distributed Treasure Hunt Game](https://github.com/suryaansh2002/cs5223-A1)** —
  fault-tolerant multiplayer game server in Java, with primary-backup
  architecture and RMI/TCP messaging to survive player and server crashes
  mid-game (NUS distributed systems coursework)
- **[IRCTC Tatkal Automation](https://github.com/suryaansh2002/IRCTC_Tatkal)** —
  booking automation for India's famously oversubscribed train ticketing
